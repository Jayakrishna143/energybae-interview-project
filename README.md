# Solar Load Calculator (energybae)

## 📖 Project Overview
This repository implements a **Solar Load Calculator** that extracts billing data from MSEDCL electricity bill images (or PDFs) using the **Google Gemini‑2.5‑Flash** vision model, processes the data, and produces a neatly formatted Excel report.  
The application consists of three main components:

1. **Backend** – FastAPI service (`backend.py`) that:
   - Receives base‑64 encoded images.
   - Calls Gemini‑2.5‑Flash to extract structured bill data.
   - Generates an Excel workbook using `openpyxl`.
   - Serves the generated file for download.
2. **Frontend** – Streamlit app (`app.py`) that:
   - Allows users to upload multiple images/PDFs.
   - Sends the images to the backend for processing.
   - Provides a download button for the resulting `Solar_Report.xlsx`.
3. **Launcher** – Simple script (`run.py`) that starts both the FastAPI backend and the Streamlit frontend in parallel.

## 📦 Installation (first time on a new machine)
1. **Clone the repository**
   ```bash
   git clone https://github.com/Jayakrishna143/energybae-interview-project.git
   cd energybae-interview-project
   ```
2. **Create a virtual environment** (recommended)
   ```bash
   python -m venv .venv
   # Activate it
   # Windows PowerShell:
   .\.venv\Scripts\Activate.ps1
   # or CMD:
   .\.venv\Scripts\activate.bat
   ```
3. **Install Python dependencies**
   ```bash
   pip install -r requirements.txt
   ```
   The `requirements.txt` includes:
   - `fastapi`, `uvicorn`, `langgraph`
   - `openpyxl`, `pillow`
   - `google-generativeai`, `python-dotenv`
   - `streamlit`, `requests`, `pdf2image` (optional for PDF support)
4. **Configure environment variables**
   - Copy the provided template (if any) or create a new `.env` file in the project root:
   ```text
   GEMINI_API_KEY=your_gemini_api_key_here
   BACKEND_URL=http://localhost:8000   # used by the Streamlit app
   ```
   **Important:** `.env` is listed in `.gitignore` so the key never gets committed.
5. **(Optional) Install system dependencies for PDF conversion**
   - On Windows, `pdf2image` requires **Poppler**. Download the latest Windows binaries from https://github.com/oschwartz10612/poppler-windows/releases and add the `bin` folder to your `PATH`.

## ▶️ Running the Application
### 1. Start the services (recommended way)
```bash
python run.py
```
The script will:
- Launch the FastAPI backend on `http://localhost:8000`.
- After a short pause, launch the Streamlit frontend on `http://localhost:8501`.
- Both services stay alive until you press **Ctrl+C**.

### 2. Manual start (if you prefer separate terminals)
- **Backend**
  ```bash
  uvicorn backend:app --host 0.0.0.0 --port 8000
  ```
- **Frontend** (in a second terminal)
  ```bash
  streamlit run app.py --server.port 8501 --server.headless true
  ```

### 3. Using the UI
1. Open your browser at `http://localhost:8501`.
2. Upload one or more bill images or PDFs.
3. Click **"Process Bills"**.
4. Once processing finishes, a **Download** button appears – click it to retrieve `Solar_Report.xlsx`.

## 🔧 Common Issues & Tips
- **Gemini API errors** – ensure your `GEMINI_API_KEY` is valid and has access to the Flash model.
- **PDF conversion fails** – verify that Poppler is correctly installed and its `bin` directory is on `PATH`.
- **CORS errors** – the backend already enables `*` origins, but if you change the host/port, make sure the frontend URL is whitelisted.
- **Port conflicts** – if port `8000` or `8501` is in use, change the values in `run.py` or start the services with custom ports and update `BACKEND_URL` accordingly.
